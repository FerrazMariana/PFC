Este foi o resultado do nosso projeto final de curso. Neste gihub estão disponíveis os arquivos usados para o desenvolvimento da placa eletronica e também os modelos de machine learning usados.
Organização do repositório:

-A pasta MPU6050 contém o código em python usado na configuração dos sensores MPU6050.

-A pasta PFC contém os códigos para tratamento do sinal e treinamento de alguns modelos de machine learning.

-A pasta PFC_projeto_eletronico contém o projeto eletrônico da placa desenvolvida.

-A pasta data contém os dados coletados
